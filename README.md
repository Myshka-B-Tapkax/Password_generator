# 🔐 Генератор паролей

Генератор случайных паролей с настройками.

## 📖 Описание

Программа создаёт пароли заданной длины, используя выбранные типы символов. Пользователь сам решает, какие символы включить в пароль.

## 🚀 Как использовать

1. Запустите файл `password_generator.py`
2. Ответьте на вопросы:
   - Добавлять цифры? (`да`/`нет`)
   - Добавлять строчные буквы? (`да`/`нет`)
   - Добавлять заглавные буквы? (`да`/`нет`)
   - Добавлять знаки препинания? (`да`/`нет`)
3. Укажите количество паролей
4. Укажите длину одного пароля
5. Получите готовые пароли

## 🛠️ Что использовано

- Python 3.12
- Модуль `random`
- Функции, циклы, условия
- Валидация ввода
- Константы
